# Harbor changes

A plain-language log of changes to the Harbor software, for reading rather than
for development.

Read it here: **https://rishanshah0811-dev.github.io/harbor-changes/**

## About this repository

Generated. Every file here is written by an automated job and force-pushed, so
there is no history to read and no pull request to open — edits made here are
overwritten on the next run.

The log is produced automatically from the development work itself. It carries
only plain descriptions of what changed; no source code, and nothing about how
the system is put together.
